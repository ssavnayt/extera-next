# extera-next

An independent Android Telegram client project based on exteraGram, with the long-term goal of updating its base to current official Telegram for Android while preserving exteraGram features.

## Upstream projects

- exteraGram: https://github.com/exteraSquad/exteraGram (GPL-2.0; archived upstream)
- Official Telegram for Android: https://github.com/DrKLO/Telegram

## Current status

This repository is a bootstrap only. The exteraGram-to-current-Telegram port has not yet been performed, and no APK has been validated from this repository.

## Build prerequisites

Follow the current instructions in the official Telegram Android repository for Android Studio, Android SDK/NDK, API keys, and signing configuration. Never commit API hashes, signing keys, passwords, or other secrets. Keep upstream license and attribution notices intact.
